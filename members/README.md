# members フォルダ
このフォルダに **`自分のGitHubユーザー名.md`** というファイルを1つ追加すると，[一覧ページ](https://tomohitoy.github.io/oss-gallery-2026/)に自分のサイトが載ります．

## ファイルの作り方
`_template.md` をコピーして，自分のユーザー名のファイルを作ります（ユーザー名が `taku-shoku` の人の例）．

```bash
cp members/_template.md members/taku-shoku.md
```

エディタで開いて，「：」のあとを書きます．

```markdown
- **ニックネーム**：たく
- **サイトのURL**：https://taku-shoku.github.io/
- **ひとこと**：週末はだいたい自転車に乗っています．好きな色の緑でまとめました．
```

| 項目 | 書くこと |
| --- | --- |
| **ニックネーム** | 一覧に大きく表示される名前．**本名のフルネームは書かないでください** |
| **サイトのURL** | `https://自分のユーザー名.github.io/`（「ユーザー名」を書きかえます） |
| **ひとこと** | サイトの紹介や見てほしいところを，1〜2文で（100文字以内が目安） |

## 決まりごと
- 追加するファイルは，**自分のユーザー名のファイル1つだけ**です．ほかの人のファイルや，`_template.md`・`README.md` は書きかえません
- `- **ニックネーム**：` のような行の形は，変えないでください（「：」のあとに書きます）
- このリポジトリは Public です．**本名のフルネーム・学籍番号・メールアドレスなど，公開したくない情報は書かないでください**

書けたら，リポジトリのいちばん上のフォルダで `bash scripts/check.sh` を実行して，確認しましょう．
